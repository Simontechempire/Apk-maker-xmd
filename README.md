# APK MAKER XMD

Telegram bot project for website-to-Android app conversion.

## Features

- URL-to-APK workflow
- ZIP/HTML upload workflow
- Force Join verification
- Referral tracking
- App profiles and history
- Version selection
- Telegram APK delivery

## Requirements

- Node.js 20+
- Telegram bot token
- Android SDK
- Gradle
- Java JDK
- Android build server

## Installation

1. Install Node.js.
2. Create a Telegram bot through BotFather.
3. Add the token to `.env`.
4. Set your Telegram numeric user ID.
5. Install dependencies:

   npm install

6. Start the bot:

   npm start

## Important

The Android build backend must be configured separately
before the bot can generate real APK files.
